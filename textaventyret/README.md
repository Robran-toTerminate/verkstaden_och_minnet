# Textäventyret

## Vad berättelsen handlar om

Du är kapten på ett skepp som just har upptäckt ett annat skepp vid horisonten.
Hur ska du agera?

## Vägvalen

Om man avvaktar händer inget

Skjuter man på skeppet skjuter de tillbaka och man kan antingen fly eller fortsätta skjuta.

Om man flyr så flyr man lyckat

Om man forsätter så är det en 50/50 att man sjunker eller att man sänker det andra skeppet
